# Scalable Unstructured Data Storage - Cloud and Open Source Solutions

This lesson lists real object store products for the unstructured data storage we learned about in [5. Scalable Unstructured Data Storage](5.%20Scalable%20Unstructured%20Data%20Storage.md).

**Terms used below:**

1. **S3-compatible:** uses the same API as Amazon S3, so code written for S3 also works with it (useful for **hybrid cloud**).
2. **Data lake:** a huge store of raw data, kept in its original format for later analysis.
3. **HPC (High-Performance Computing):** running very heavy computations on many powerful machines.
4. **Kubernetes:** a popular platform for running and managing containerized applications.
5. **Commodity hardware:** ordinary, inexpensive standard machines, not special-purpose devices.
6. **Block storage:** storage presented as raw disk volumes (like a hard drive attached to a server).

---

### Cloud-Based Object Stores

| Product | Description | Use cases |
| --- | --- | --- |
| **Amazon S3** (Simple Storage Service) | Highly scalable cloud storage that keeps objects in **buckets**. Stores and protects any amount of data. | Websites, cloud-native apps, backups, archiving, machine learning, analytics |
| **GCP Cloud Storage** | Google Cloud's **managed** service for storing unstructured data | Companies of all sizes |
| **Azure Blob Storage** | Microsoft's massively scalable and secure object storage | Cloud-native workloads, archives, data lakes, HPC, machine learning |
| **Alibaba Cloud OSS** (Object Storage Service) | **Fully managed**, enterprise-ready object storage | Store and access any amount of data from anywhere |

---

### Open-Source and Third-Party Object Stores

These are options for **on-premise** or **hybrid cloud** setups.

### 1. OpenIO

1. **Software-defined**, open-source object storage
2. Ideal for **Big Data, HPC and AI**
3. **S3-compatible**
4. Deploy **on-premises** or **cloud-hosted**, on any hardware we choose

### 2. MinIO

1. **High-performance**, **S3-compatible** object storage
2. **Native to Kubernetes**
3. **100% open source**, under the **GNU AGPL v3** license

### 3. Ceph

1. Open-source, **reliable and scalable** storage
2. A **unified** storage service with **object, block and file** interfaces, all from a **single cluster**
3. Built from **commodity hardware**

**Real-world example:** MinIO is like having your own private "S3" in your company's data center. Apps talk to it exactly like they would talk to Amazon S3.

**Key idea:** Every major cloud has its own object store (S3, GCP Cloud Storage, Azure Blob, Alibaba OSS). For on-premise or hybrid setups, OpenIO and MinIO offer S3-compatible object storage, and Ceph offers object, block and file storage from one cluster.

---

## Short Note

- **Cloud object stores:**
  - **Amazon S3:** buckets, any amount of data (websites, backups, archiving, ML, analytics).
  - **GCP Cloud Storage:** managed unstructured storage for any company size.
  - **Azure Blob Storage:** massive scale (archives, data lakes, HPC, ML).
  - **Alibaba Cloud OSS:** fully managed and enterprise-ready.
- **Open source / third party** (on-premise and hybrid):
  - **OpenIO:** software-defined and S3-compatible, for Big Data, HPC and AI, on any hardware.
  - **MinIO:** high-performance, S3-compatible, Kubernetes-native, AGPL v3.
  - **Ceph:** object + block + file storage from one cluster of commodity hardware.

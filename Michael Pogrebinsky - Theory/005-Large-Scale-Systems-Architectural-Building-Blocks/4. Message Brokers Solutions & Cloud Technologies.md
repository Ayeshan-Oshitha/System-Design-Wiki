# Message Brokers Solutions & Cloud Technologies

This lesson lists real products for the message broker we learned about in [3. Message Brokers](3.%20Message%20Brokers.md).

**Two terms used below:**

1. **Fully managed:** the cloud provider runs, scales and maintains the service for us. We just use it.
2. **Event streaming / data ingestion:** taking in a continuous, very large flow of events (such as clicks or sensor readings) and passing it on for processing.

---

### Open-Source Message Brokers

### 1. Apache Kafka

1. The **most popular** open-source message broker today
2. A **distributed event streaming platform**, used by thousands of companies for:
   - High-performance data pipelines
   - Streaming analytics
   - Data integration
   - Mission-critical applications

### 2. RabbitMQ

1. A **widely deployed** open-source message broker
2. Used worldwide, from **small startups** to **large enterprises**

**Real-world example:** Kafka is like a busy news wire that many teams read from at once. RabbitMQ is like a post office that delivers each letter to the right mailbox.

---

### Cloud-Based Message Brokers

### 1. Amazon Simple Queue Service (SQS)

A **fully managed message queuing** service. It lets us **decouple and scale** microservices, distributed systems and serverless applications.

### 2. GCP Pub/Sub and Cloud Tasks

Google Cloud Platform offers two solutions:

1. **Pub/Sub:** the **publisher/subscriber** solution
2. **Cloud Tasks:** the **message queue** solution

(The course links to an article comparing the two.)

### 3. Microsoft Azure

| Service | What it is | Highlights |
| --- | --- | --- |
| **Service Bus** | Fully managed **enterprise** message broker | Message **queues** and **publish-subscribe topics** |
| **Event Hubs** | Fully managed **real-time data ingestion** service | Streams **millions of events per second** from any source. Works with **Apache Kafka** clients without code changes. Perfect for **Big Data**. |
| **Event Grid** | Reliable, **serverless** event delivery system at massive scale | Uses **publish-subscribe**. Dynamically scalable, low cost (**pay-as-you-go**), and guarantees **"at least once" delivery** of each event |

**"At least once" delivery** means every event is guaranteed to arrive, but it may sometimes arrive **more than once**.

## Short Note

- **Open source:**
  - **Apache Kafka:** the most popular, a distributed event streaming platform for data pipelines, streaming analytics and integration.
  - **RabbitMQ:** widely deployed, from startups to enterprises.
- **Cloud:**
  - **AWS SQS:** a fully managed queue to decouple and scale microservices and serverless apps.
  - **GCP:** **Pub/Sub** for publish/subscribe, and **Cloud Tasks** for queues.
  - **Azure:**
    - **Service Bus:** an enterprise broker with queues and pub/sub topics.
    - **Event Hubs:** real-time ingestion of millions of events per second, Kafka-compatible, for Big Data.
    - **Event Grid:** serverless pub/sub, pay-as-you-go, with **at-least-once** delivery.

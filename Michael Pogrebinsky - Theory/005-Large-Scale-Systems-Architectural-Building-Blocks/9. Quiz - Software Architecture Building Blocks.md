# Quiz 10: Software Architecture Building Blocks

This quiz covers all of Section 5: GSLB, load balancers, message brokers, API Gateway and CDN.


**Scenario (Questions 1 and 2):** We are designing a highly scalable **video-on-demand** system where users watch movies in their browsers. To support millions of users around the world, we deployed our services in **5 data centers**, each running multiple instances of our frontend service.

**Question 1:** Which architectural building block should we use to make sure a user in **India** gets the home page, with the catalog of all our movies, from the **nearest data center**?

1. CDN
2. API Gateway
3. GSLB
4. Message Broker

**Answer:** 3. GSLB.

A GSLB knows the user's location (from their IP) and the health of every data center, so it returns the address of the nearest data center's load balancer.

**Question 2:** Which architectural building block should we use to make sure the traffic **inside each data center** is evenly distributed among all our frontend service instances?

1. CDN
2. Message Broker
3. Software/Hardware Load Balancer
4. GSLB

**Answer:** 3. Software/Hardware Load Balancer.

A GSLB picks the data center. Inside it, a load balancer collocated with the servers spreads the requests across the healthy frontend instances.

**Question 3:** We decided to also build a dedicated **mobile app** that talks to our system through a **different API**. Which architectural building block should we use so that we **don't need to modify our internal services** to support the new API?

1. CDN
2. API Gateway
3. GSLB
4. Message Broker
5. Software/Hardware Load Balancer

**Answer:** 2. API Gateway.

The API Gateway hides our internal services behind its own API. It can expose the new mobile API and translate it to the existing service calls (API composition and protocol translation).

**Question 4:** Once the user picks a movie, we want them to watch it **smoothly with minimal buffering**, especially for **4K** movies. Which architectural building block should we use?

1. CDN
2. GSLB
3. Message Broker
4. API Gateway

**Answer:** 1. CDN.

A CDN caches video files on edge servers close to the user and delivers on-demand video streams, so large 4K files load quickly with little buffering.

**Question 5:** After the movie, we prompt the user to leave a review and rating. Which architectural building block should we use so we **never lose any reviews**, but the user **doesn't have to wait** for the review to be saved in a database?

1. CDN
2. GSLB
3. Software/Hardware Load Balancer
4. Message Broker
5. API Gateway

**Answer:** 4. Message Broker.

The message broker stores the review in its queue right away, so the user doesn't wait (asynchronous). It also prevents messages from being lost (fault tolerance), and a service saves the review to the database later.

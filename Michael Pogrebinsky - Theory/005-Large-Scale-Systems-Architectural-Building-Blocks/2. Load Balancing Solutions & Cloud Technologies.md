# Load Balancing Solutions & Cloud Technologies

This lesson lists real products for the load balancing types we learned in [1. DNS, Load Balancing & GSLB](1.%20DNS,%20Load%20Balancing%20&%20GSLB.md).

**Two terms used below:**

1. **Layer 7 (L7):** the load balancer looks at **HTTP/HTTPS** requests (the web level), so it can make advanced, smart decisions.
2. **Layer 4 (L4):** the load balancer works at the **TCP/UDP** level (the network connection level). It is simpler and very fast.

---

### Open-Source Software Load Balancers

### 1. HAProxy

1. A **free, open-source**, reliable, high-performance **TCP/HTTP** load balancer
2. Especially suited to **very high-traffic websites**, and powers a big part of the world's most visited ones
3. Considered the **de-facto standard** open-source load balancer, shipped with most mainstream Linux distributions
4. Supports most Unix-style operating systems

### 2. NGINX

1. A **free, open-source**, high-performance **HTTP server** and **reverse proxy** (load balancer)
2. Known for its high performance, stability, rich feature set and **simple configuration**

---

### Cloud-Based Load Balancers

### 1. AWS: Elastic Load Balancing (ELB)

A highly scalable load balancing solution. It is ideal when running on AWS, and integrates seamlessly with all AWS services. It has **4 modes**:

| Mode | Layer | Best for |
| --- | --- | --- |
| **Application Load Balancer** | Layer 7 | Advanced load balancing of HTTP and HTTPS traffic |
| **Network Load Balancer** | Layer 4 | TCP and UDP traffic |
| **Gateway Load Balancer** | | Deploying, scaling and managing third-party virtual appliances |
| **Classic Load Balancer** | Layers 4 and 7 | Routing traffic to EC2 instances |

### 2. GCP: Cloud Load Balancing

Google's highly scalable and robust load balancing solution. It lets us put our resources behind **a single IP address**, either externally accessible or internal to our VPC (Virtual Private Cloud, our private network in the cloud). Some of its types:

| Type | Layer | Facing |
| --- | --- | --- |
| **External HTTP(S) Load Balancer** | Layer 7 | External (internet) |
| **Internal HTTP(S) Load Balancer** | Layer 7 | Internal |
| **External TCP/UDP Network Load Balancer** | Layer 4 | External (internet) |
| **Internal TCP/UDP Load Balancer** | Layer 4 | Internal |

### 3. Microsoft Azure Load Balancer

| Type | Best for |
| --- | --- |
| **Standard Load Balancer** | Public and internal Layer 4 load balancing |
| **Gateway Load Balancer** | High performance and high availability for third-party Network Virtual Appliances |
| **Basic Load Balancer** | Small-scale applications |

---

### GSLB Solutions

1. **Amazon Route 53:** a highly available and scalable cloud **DNS** web service
2. **AWS Global Accelerator:** a networking service that improves the availability, performance and security of public applications
3. **Google Cloud Load Balancer + Cloud DNS:** reliable, resilient, low-latency DNS from Google's worldwide network, with everything needed to register, manage and serve domains
4. **Azure Traffic Manager:** **DNS-based** load balancing

---

### Summary Table

| Type | Products |
| --- | --- |
| **Open-source software LB** | HAProxy, NGINX |
| **Cloud LB** | AWS ELB, GCP Cloud Load Balancing, Azure Load Balancer |
| **GSLB** | Amazon Route 53, AWS Global Accelerator, Google Cloud LB + Cloud DNS, Azure Traffic Manager |

**Key idea:** HAProxy and NGINX are popular open-source software load balancers. Each cloud (AWS, GCP, Azure) offers its own Layer 4 and Layer 7 load balancers, plus DNS-based GSLB services such as Route 53 and Azure Traffic Manager.

---

## Short Note

- **Layer 7** = HTTP/HTTPS (smart routing). **Layer 4** = TCP/UDP (fast, connection level).
- **Open source:**
  - **HAProxy:** free TCP/HTTP load balancer for very high traffic, the de-facto standard, ships with Linux.
  - **NGINX:** free HTTP server and reverse proxy, fast, stable, simple to configure.
- **Cloud:**
  - **AWS ELB:** Application (L7), Network (L4), Gateway (third-party appliances), Classic (L4 + L7, EC2).
  - **GCP Cloud Load Balancing:** one IP, with external and internal HTTP(S) (L7) and TCP/UDP (L4) options.
  - **Azure:** Standard (L4), Gateway (third-party appliances), Basic (small apps).
- **GSLB:** Route 53 (DNS), AWS Global Accelerator, Google Cloud LB + Cloud DNS, and Azure Traffic Manager (DNS-based).

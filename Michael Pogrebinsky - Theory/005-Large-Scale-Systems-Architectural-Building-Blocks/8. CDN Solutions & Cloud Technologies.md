# CDN Solutions & Cloud Technologies

This lesson lists real CDN products for the Content Delivery Network we learned about in [7. Content Delivery Network - CDN](7.%20Content%20Delivery%20Network%20-%20CDN.md).

**Terms used below:**

1. **Static content:** content that is the same for every user, such as images, CSS and JavaScript files.
2. **Dynamic content:** content generated per request or per user, such as a personalized page or an API response.
3. **Unmetered DDoS protection:** DDoS protection with no limit on attack size and no extra charge for the attack traffic.

---

### Dedicated CDN Providers

### 1. Cloudflare

1. **Ultra-fast** delivery of **static and dynamic** content over its global edge network
2. Helps **reduce bandwidth costs**
3. Built-in **unmetered DDoS protection**

### 2. Fastly

1. **Deliver@Edge:** a modern, efficient and **highly configurable** CDN
2. Gives us the freedom to **control how our content is cached**, so we can deliver what users want quickly

### 3. Akamai

A large variety of offerings, including:

1. API Acceleration
2. Global Traffic Management
3. Image & Video Management
4. Media Delivery
5. And much more

---

### Cloud-Based CDNs

### 1. Amazon CloudFront

A CDN service built for **high performance, security and developer convenience**. Use cases include:

1. Delivering fast, secure **websites**
2. Accelerating **dynamic content** delivery and **APIs**
3. **Live streaming**
4. **Video-on-demand**

### 2. Google Cloud Platform CDN

Fast, reliable **web and video** content delivery with **global scale and reach**.

### 3. Microsoft Azure Content Delivery Network

1. **Global coverage**
2. **Full integration** with Azure services
3. **Simple setup**

---

### Summary Table

| Type | Products |
| --- | --- |
| **Dedicated CDN providers** | Cloudflare, Fastly, Akamai |

---

**Key idea:** Cloudflare, Fastly and Akamai are dedicated CDN providers, and each cloud has its own CDN (Amazon CloudFront, GCP CDN, Azure CDN) that integrates with its other services.

---

## Short Note

- **Dedicated providers:**
  - **Cloudflare:** fast static and dynamic delivery, lower bandwidth costs, and unmetered DDoS protection.
  - **Fastly (Deliver@Edge):** highly configurable, with full control over caching.
  - **Akamai:** many offerings, including API acceleration, global traffic management, image/video management and media delivery.
- **Cloud:**
  - **Amazon CloudFront:** fast, secure websites, dynamic content and APIs, live streaming and video-on-demand.
  - **GCP CDN:** web and video delivery at global scale.
  - **Azure CDN:** global coverage, Azure integration and simple setup.

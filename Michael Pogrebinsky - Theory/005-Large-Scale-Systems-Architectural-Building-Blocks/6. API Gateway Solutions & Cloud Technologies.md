# API Gateway Solutions & Cloud Technologies

This lesson lists real products for the API Gateway we learned about in [5. API Gateway](5.%20API%20Gateway.md).

**Terms used below:**

1. **Platform-agnostic:** works on any platform or cloud, not tied to one vendor.
2. **Plugins:** add-ons that give the gateway new features without changing its core.
3. **LLM:** Large Language Model, an AI model such as Claude or GPT.
4. **MCP:** Model Context Protocol, a standard way for AI models to connect to tools and data.
5. **Serverless:** we run code without managing any servers. The cloud handles them for us.

---

### Open-Source API Gateways

### 1. Netflix Zuul

1. A **free, open-source** application gateway written in **Java**
2. Provides **dynamic routing, monitoring, resiliency, security**, and more

### 2. Kong Gateway

1. A **cloud-native, platform-agnostic**, scalable gateway for **APIs, LLMs and MCP**
2. Known for its **high performance** and **extensibility through plugins**
3. Advanced **AI traffic** features:
   - Support for multiple LLMs
   - Semantic security (checking the meaning of AI requests, not just their format)
   - MCP traffic security and analytics

---

### Cloud-Based API Gateways

### 1. Amazon API Gateway

1. A **fully managed** service to easily **create, publish, maintain, monitor and secure** APIs at any scale
2. Supports **RESTful APIs** and **WebSocket APIs** (bi-directional, meaning two-way, communication between client and server)

### 2. Google Cloud Platform

| Product | What it does |
| --- | --- |
| **GCP API Gateway** | Secure access to our services through a well-defined **REST API** that is consistent across all services, no matter how each is implemented. Designed for **serverless** workloads on GCP. |
| **Apigee** | Google Cloud's **API management** product to build, manage and secure APIs for any use case, any scale and any environment: **on-premises**, in Google Cloud, or **hybrid** (a mix of both) |

### 3. Microsoft Azure API Management

Helps organizations **publish APIs** to **external, partner and internal developers**, to unlock the potential of their data and services.

## Short Note

- **Open source:**
  - **Netflix Zuul:** a free Java gateway for dynamic routing, monitoring, resiliency and security.
  - **Kong:** a cloud-native, platform-agnostic, high-performance gateway with plugins, plus AI features (multi-LLM, semantic security, MCP traffic security and analytics).
- **Cloud:**
  - **Amazon API Gateway:** fully managed (create, publish, monitor, secure), with REST and WebSocket (two-way) APIs.
  - **GCP API Gateway:** one consistent REST API over all services, for serverless workloads.
  - **Apigee:** Google's full API management product for on-premises, cloud or hybrid.
  - **Azure API Management:** publishes APIs to external, partner and internal developers.
